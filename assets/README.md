# Asset Inventory

This directory contains generated visual-development assets. They are concept art, not final print files.

## Board

- `board/board-key-art.png` — atmospheric map painting intended beneath a future rules overlay.
- `board/board-layout-concept.png` — board-zoning and component-layout mockup.

## Cards

- `cards/chronicle-card-art-sheet.png` — nine market-card illustration directions.
- `cards/starting-deck-art-sheet.png` — the seven unique shared starting-card illustrations.
- `cards/commander-portraits.png` — eight leader portrait directions.

The exact prompts used to create these images are preserved in `ART_DIRECTION.md` and in the project handoff. Raster text, if any appears in a generated concept, is non-authoritative and must not be used as rules copy.
